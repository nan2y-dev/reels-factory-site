1. 개요

Reels Factory는 운영자 본인이 소유한 단일 유튜브 채널에 쇼츠 영상을 자동으로 제작·업로드하기 위한 개인용 도구입니다. 일반 사용자가 가입하거나 로그인하는 서비스가 아니며, 운영자 본인의 계정에만 연결되어 동작합니다.

2. 수집하는 정보

Google OAuth를 통해 다음 권한만 사용합니다.

  • youtube — 운영자 본인 채널에 영상 업로드·삭제·수정
  • youtube.readonly — 운영자 본인 채널의 영상 목록과 조회수·좋아요 수 조회

이 앱은 다른 사용자의 유튜브 계정, 개인정보, 시청 기록에 접근하거나 이를 수집하지 않습니다.

3. 이용 목적

수집한 정보는 오직 자동 업로드 파이프라인 운영과, 조회수가 낮은 영상을 정리하는 용도로만 사용됩니다. 광고, 프로파일링, 제3자 분석 목적으로 사용되지 않습니다.

4. 정보 저장 및 공유

업로드 기록과 영상 통계는 운영자가 직접 관리하는 로컬 서버(라즈베리파이)에만 저장됩니다. 외부 서버나 제3자에게 판매·공유·전송되지 않으며, 업로드 결과 알림은 운영자 본인의 비공개 Slack 채널로만 전송됩니다.

5. Google API 서비스 사용자 데이터 정책

본 애플리케이션의 Google API 사용 및 전송은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 준수합니다.

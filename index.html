Reels Factory

한 사람이 개인 유튜브 채널 하나를 위해 운영하는 쇼츠 자동 제작·업로드 파이프라인입니다.

개인용 단일 채널 비상업적 도구 라즈베리파이 상시 구동

무엇을 하나요

매일 정해진 시간에 아래 단계를 자동으로 거쳐 쇼츠 1편을 만들고, 개발자 본인 소유 유튜브 채널에 업로드합니다.

  1. 01

    주제 선정

    실시간 트렌드 키워드 또는 큐레이션된 건강·심리 주제 풀에서 선택

  2. 02

    대본 생성

    로컬 LLM(Ollama)으로 40~45초 분량의 한국어 나레이션 작성

  3. 03

    음성 합성

    한국어 TTS로 나레이션을 음성으로 변환

  4. 04

    영상 조립

    스톡 영상·자막을 합쳐 세로형 쇼츠 영상 완성

  5. 05

    업로드

    YouTube Data API로 개발자 본인 채널에 예약 업로드, 이후 조회수를 참고해 저성과 영상 정리

이 앱에 대해

Google API는 개발자 본인의 유튜브 채널을 관리하는 용도로만 사용됩니다. 다른 사용자의 계정이나 데이터에는 접근하지 않으며, 외부에 공개 배포되지 않는 개인 프로젝트입니다.

자세한 데이터 처리 방식은 개인정보처리방침을 참고하세요.
